# Task 29 — Relationship Analysis Using Python

## Project Overview

This project demonstrates relationship analysis between two numerical variables using Python, Pandas, NumPy, and Matplotlib.

A sample student performance dataset containing study hours and examination marks is used to create a scatter plot and identify the relationship between the variables.

Pearson correlation is also calculated to understand the strength and direction of the linear association.

## Objectives

- Create a scatter plot using two numerical variables.
- Analyze the relationship between study hours and exam marks.
- Calculate the Pearson correlation coefficient.
- Understand positive and negative relationships.
- Identify the strength of the relationship.
- Record at least three observations from the visualization.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Jupyter Notebook

## Dataset Description

The project uses a manually created student performance dataset containing 20 fictional student records.

The dataset contains three columns:

| Column | Description |
|---|---|
| student_id | Unique student identifier |
| study_hours | Number of hours spent studying |
| exam_marks | Marks obtained in the examination |

## Visualization

### Scatter Plot — Study Hours vs Exam Marks

The scatter plot represents study hours on the X-axis and examination marks on the Y-axis.

Each point represents one student's observation.

A regression trend line is also added to help visualize the direction of the relationship.

## Correlation Analysis

Pearson correlation coefficient:

**0.9754**

The result indicates a strong positive linear association between study hours and examination marks in the sample dataset.

## Key Observations

1. The sample dataset shows a strong positive relationship between study hours and exam marks.
2. Students with higher study hours generally obtained higher marks.
3. The Pearson correlation coefficient is approximately 0.9754.
4. Study hours range from 1 to 10.5 hours.
5. Examination marks range from 35 to 96.
